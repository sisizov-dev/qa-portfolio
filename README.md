# qa-portfolio
Привет! Я начинающий QA-инженер. Здесь собраны мои учебные проекты 
по ручному тестированию, API-тестированию и автоматизации.

## Что внутри

### Ручное тестирование учебных приложений образовательной платформы
- **API-тестирование приложения заказа товаров** — чек-листы, баг-репорты. 79 проверок, 30 баг-репортов.
- **Мобильное приложение «Яндекс Метро» сервис построения маршрутов и расчета времени поездок** — функциональное и
  регрессионное тестирование. 69 проверок, 13 баг-репортов.
- **«Маршруты - сервис построения маршрутов и расчета времени поездок на разных видах транспорта» — тест-анализ** — КЭ и ГЗ,
  тест-кейсы, баг-репорты. 66 тест-кейсов, 17 баг-репортов.
- **«Маршруты - сервис построения маршрутов и расчета времени поездок на разных видах транспорта» — вёрстка, оплата,
  функционал** — чек-листы, тест-кейсы, баг-репорты. 105 проверок, 34 баг-репорта.
