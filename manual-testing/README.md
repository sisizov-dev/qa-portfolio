# Ручное тестирование

## 1. API-тестирование
Тестирование API учебного сервиса через Postman.

**Что проверял:**
- Работа с наборами: `POST /api/v1/kits/{id}/products`
- Работа с курьерами: `POST /fast-delivery/v3.1.1/calculate-delivery.xml`
- Работа с корзиной: `GET`, `PUT`, `DELETE /api/v1/orders/:id`

**Результат:** 79 проверок, 30 баг-репортов. Более 50% — критические.

## 2. Мобильное приложение «Яндекс Метро»
Тестирование после рефакторинга Android-приложения перед релизом в стор.

**Что делал:**
- Тестирование затронутых изменением частей продукта
- Регрессионное тестирование

**Результат:** 69 проверок, 13 баг-репортов.

## 3. «Маршруты» — тест-анализ
Приложение рассчитывает время и стоимость поездки в зависимости от вида транспорта.

**Что делал:**
- Тест-анализ
- Определение классов эквивалентности и граничных значений
- Составление тест-кейсов и баг-репортов

**Результат:** 66 тест-кейсов, 17 баг-репортов.

## 4. «Маршруты» — вёрстка, оплата, функционал
**Что делал:**
- Чек-листы на вёрстку
- Чек-листы на оплату (тестирование оплаты картой)
- Тест-кейсы на функционал

**Результат:** 105 проверок, 5 тест-кейсов, 34 баг-репорта.
